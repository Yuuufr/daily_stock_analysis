# 通知服务

多渠道通知发送系统，支持 12+ 种通知渠道。

## 什么是通知服务？

`NotificationService` 汇总分析结果生成 Markdown 报告，并通过多种渠道发送到用户。

**关键特征**：
- 多渠道同时推送
- 自动识别渠道类型
- Markdown 转图片（可选）
- 支持分组发送

## 代码位置

| 方面 | 位置 |
|------|------|
| 核心类 | `src/notification.py` |
| 发送器 | `src/notification_sender/{channel}_sender.py` |
| 测试 | `tests/test_notification_*.py` |

## 支持渠道

| 渠道 | 发送器 | 配置项 |
|------|--------|--------|
| 企业微信 | `wechat_sender.py` | `WECHAT_WEBHOOK_URL` |
| 飞书 | `feishu_sender.py` | `FEISHU_WEBHOOK_URL` |
| Telegram | `telegram_sender.py` | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| Discord | `discord_sender.py` | `DISCORD_WEBHOOK_URL` |
| Slack | `slack_sender.py` | `SLACK_BOT_TOKEN` |
| 邮件 | `email_sender.py` | `EMAIL_SENDER`, `EMAIL_PASSWORD` |
| PushPlus | `pushplus_sender.py` | `PUSHPLUS_TOKEN` |
| Server酱3 | `serverchan3_sender.py` | `SERVERCHAN3_SENDKEY` |
| Pushover | `pushover_sender.py` | `PUSHOVER_USER_KEY`, `PUSHOVER_API_TOKEN` |
| 自定义 Webhook | `custom_webhook_sender.py` | `CUSTOM_WEBHOOK_URLS` |

## 发送器接口

```python
class NotificationSender(ABC):
    """通知发送器基类"""
    
    @property
    def channel(self) -> str:
        """渠道名称"""
        
    def send(
        self,
        content: str,
        title: Optional[str] = None,
        **kwargs
    ) -> Tuple[bool, Optional[str]]:
        """
        发送通知
        
        Returns:
            Tuple[是否成功, 错误信息]
        """
```

## Markdown 转图片

某些渠道不支持 Markdown，可配置转为图片发送：

```bash
# 配置转图渠道
MARKDOWN_TO_IMAGE_CHANNELS=telegram,wechat,custom

# 配置转图引擎
MD2IMG_ENGINE=wkhtmltoimage  # 或 markdown-to-file
```

## 分组发送

支持股票分组发往不同邮箱：

```bash
STOCK_GROUP_1=600519,300750
EMAIL_GROUP_1=user1@example.com

STOCK_GROUP_2=002594,AAPL
EMAIL_GROUP_2=user2@example.com
```
