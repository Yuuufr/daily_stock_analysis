# 数据源适配

多数据源 fallback 机制，确保数据获取的高可用性。

## 什么是数据源适配？

`DataFetcherManager` 是统一的数据获取接口，管理多个数据源的优先级和自动降级。当高优先级数据源失败时，自动尝试低优先级数据源。

**关键特征**：
- 多数据源优先级配置
- 失败自动降级
- 统一数据接口
- 支持实时行情和历史数据

| 优先级 | 数据源 | 适用市场 | 说明 |
|--------|--------|----------|------|
| 1 | eFinance | A股 | 东方财富数据 |
| 2 | AkShare | A股/港股 | 免费开源 |
| 3 | Tushare | A股 | 需要 Token |
| 4 | Pytdx | A股 | 通达信数据 |
| 5 | Baostock | A股 | 备用源 |
| 6 | YFinance | 美股 | Yahoo Finance |

## 统一接口

```python
class BaseFetcher:
    """数据获取器基类"""
    
    def get_stock_info(self, code: str) -> Optional[StockInfo]:
        """获取股票基本信息"""
        
    def get_historical_data(
        self,
        code: str,
        days: int = 250
    ) -> Optional[pd.DataFrame]:
        """获取历史 K 线数据"""
        
    def get_realtime_quote(self, code: str) -> Optional[StockQuote]:
        """获取实时行情"""
        
    def get_chip_distribution(self, code: str) -> Optional[ChipDistribution]:
        """获取筹码分布"""
```

## Fallback 机制

```python
def get_historical_data(self, code: str, days: int = 250) -> Optional[pd.DataFrame]:
    """获取历史数据，自动降级"""
    
    # 按优先级尝试各数据源
    for fetcher in [eFinance, akshare, tushare, pytdx, baostock]:
        try:
            data = fetcher.get_historical_data(code, days)
            if data is not None and not data.empty:
                return data
        except Exception as e:
            logger.warning(f"{fetcher.__class__.__name__} failed: {e}")
            continue
    
    # 所有数据源都失败
    logger.error(f"All fetchers failed for {code}")
    return None
```
