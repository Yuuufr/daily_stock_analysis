# 基本信息

## 工作流程

### 1. 初始化阶段

```
main.py 启动
    ↓
setup_env() - 加载环境配置
    ↓
initialize_quant_module() - 初始化量化模块
    │  - 注册 9 个内置因子（动量、波动率、趋势、RSI、MACD、布林带等）
    ↓
QuantIntegration.setup_weekend_training() - 启动周末调度器
    │  - 后台线程监控，每周六 07:00 自动执行训练
    ↓
日志输出
```

### 2. 日常分析流程（每日任务）

```
python main.py
    ↓
解析命令行参数（--stocks, --debug, --schedule 等）
    ↓
获取自选股列表或指定股票
    ↓
启动分析 Pipeline（多线程）
    ↓
Pipeline 运行：
    1. 数据获取（data_provider 多源 fallback）
    2. 技术分析（趋势、均线、MACD、RSI）
    3. 新闻情报搜索
    4. AI 决策（LLM 生成决策仪表盘）
    5. 报告生成
    ↓
NotificationService.send() - 推送结果
    │  企业微信 / 飞书 / Telegram / 邮件
```

### 3. 周末训练（自动）

```
每周六 07:00（自动触发，无需手动）
    ↓
WeekendTrainer.run_full_training()
    ↓
流程：
    1. 检测市场 Regime（牛/熊/震荡）
    2. 准备训练数据
    3. 历史因子回测（IC/IR 分析）
    4. 特征重要性分析
    5. 训练 sklearn 模型（随机森林、梯度提升）
    6. 训练 PyTorch 模型（MLP）
    7. 模型选择与保存
    ↓
发送训练报告到通知渠道
```

### 4. 定时调度模式

```
python main.py --schedule
    ↓
启用 GitHub Actions 风格的每日定时任务
    ↓
每天北京时间 14:40 自动运行分析
    ↓
结果推送
```

**简单说**：启动后量化模块先初始化，然后正常分析股票，周末自动训练模型。
